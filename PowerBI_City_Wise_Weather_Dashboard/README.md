# 🌦️ City-Wise Weather Trends & Insights Dashboard

## 📌 Overview
This Power BI project analyzes city-wise weather data to uncover trends in temperature, humidity, wind speed, and overall comfort levels across major Indian cities.

## 🛠️ Tools Used
- Power BI
- CSV Dataset
- Data Modeling & DAX
- Data Visualization

## 📊 Key Insights
- Average temperature trends over time
- Weather condition frequency analysis
- Comfort level classification (Comfortable vs Uncomfortable)
- City-level filtering for comparative analysis
- KPI cards for temperature, humidity, and wind speed
